# WorkBoard

Корпоративная платформа рабочих обсуждений для сотрудников компании.  

## О проекте

Веб-приложение, где команды ведут темы и обсуждения, комментируют и создают посты, прикрепляют файлы и разграничивают контент по отделам. 

### Основные возможности (целевой MVP)

- Посты с типами: обсуждение проекта, информация, объявление и др.
- Комментарии к постам (ветки обсуждения)
- Вложения (изображения и файлы)
- Общая лента и ленты по отделам
- Поиск и фильтры по постам
- Модерация контента
- Профиль: настройки, смена пароля, история активности
- Модуль peer-recognition (лимиты, антинакрутка, рейтинги)

## Стек

- **Backend:** Java + Spring Boot
- **Frontend:** TypeScript + React (Vite)
- **База данных:** PostgreSQL
- **Инфраструктура:** Docker
